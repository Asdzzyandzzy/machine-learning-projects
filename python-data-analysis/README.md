# Python Data Analysis

## Overview

This project practices core Python data analysis workflows using small tabular datasets. The notebook works through file loading, exploratory checks, array operations, and basic visualization.

## What I Built / Implemented

- Loaded CSV and text data with pandas.
- Explored Titanic passenger data and derived fare-related summaries.
- Used NumPy arrays to analyze toy user-movie ratings.
- Filled missing values and compared simple aggregation strategies.

## Key Technical Points

- pandas file I/O and DataFrame inspection
- NumPy indexing, broadcasting, and missing-value handling
- Basic plotting with Matplotlib
- Reproducible notebook-based analysis

## How to Run

Create the environment from the repository root if needed:

```bash
conda env create -f environment.yml
conda activate cpsc330
jupyter lab
```

Then open `python-data-analysis.ipynb` from this folder and run the cells from top to bottom.

## Results, Outputs, or Examples

The notebook includes executed outputs for the data-loading exercises, Titanic fare analysis, and movie-rating array operations. The local `data/` folder contains the small CSV and text files used by the notebook.

## Repository Notes

The notebook is kept as an executable analysis artifact. Some setup cells are retained because they were part of the original notebook structure.
