# Model Communication

## Overview

This project focuses on explaining machine learning concepts and results clearly. It includes a survival analysis discussion and a short write-up based on the Airbnb price modeling project.

## What I Built / Implemented

- Explained why churn modeling needs time-to-event framing and censoring awareness.
- Discussed interpretation of survival functions.
- Wrote a concise project-style explanation of the Airbnb price prediction workflow.
- Summarized task framing, dataset context, model choices, results, caveats, and conclusions for a non-specialist reader.

## Key Technical Points

- Survival analysis concepts
- Clear communication of modeling assumptions
- Result interpretation and caveat writing
- Translating a technical model workflow into a readable narrative

## How to Run

From the repository root:

```bash
conda env create -f environment.yml
conda activate ml-portfolio
jupyter lab
```

Open `model-communication.ipynb` to review the written responses and saved outputs.

## Results, Outputs, or Examples

The notebook includes a short Airbnb pricing explanation with sections for task, dataset, model, results, caveats, and conclusion. Supporting images are included in this folder.

## Repository Notes

This folder is more communication-oriented than code-heavy. It is included because graduate reviewers often care about whether technical work can be explained clearly.
